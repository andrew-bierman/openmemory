# Support

OpenMemory is currently an alpha open-source project.

Use GitHub Issues for:

- Reproducible bugs.
- Documentation gaps.
- Cloudflare deployment problems.
- Feature requests that fit the roadmap.

Use GitHub Discussions after they are enabled for:

- Architecture questions.
- Self-hosting help.
- MCP client compatibility notes.
- Product feedback and examples.

For vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of opening a
public issue.
